TCAS

Global 3D & 2D Earth Hazard Monitor

ระบบติดตามแผ่นดินไหวและภูมิศาสตร์โลก 2D และ 3D

แนวคิดและที่มา: เว็บแอปพลิเคชันสำหรับจำลองลูกโลกเสมือนจริง 3 มิติ (3D Globe) และแผนที่ภูมิสารสนเทศ 2 มิติ (2D GIS Map) ที่รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ (iOS & Android) สลับมุมมองได้อย่างอิสระ พร้อมระบบแสดงชื่อประเทศครบถ้วนทุกทวีปทั่วโลก เชื่อมต่อข้อมูลแผ่นดินไหวสดจาก USGS

Tech Stack & Data Sources:
• 2D Mapping Engine: Leaflet.js Interactive GIS (Esri 4K Satellite)
• 3D Virtual Globe: Three.js & Globe.gl WebGL Rendering
• Earthquake Feed: USGS Real-time GeoJSON API (100% Free)
• Weather Data: Open-Meteo REST API
• Mobile Optimized: Responsive Floating Drawers & Gestures
