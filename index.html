Global 3D Earth Hazard & Geographic Telemetry System

แนวคิดและวัตถุประสงค์: โครงงานพัฒนาเว็บแอปพลิเคชันจำลองลูกโลกสามมิติ (3D Virtual Globe) ทางภูมิศาสตร์และธรณีฟิสิกส์ บูรณาการชั้นข้อมูลพิกัดภูมิศาสตร์ (Geographic Graticule), ป้ายชื่อประเทศ (Country Boundaries), พิกัดเมืองหลวง (City Coordinates: Latitude/Longitude), รอยต่อแผ่นเปลือกโลก (Tectonic Boundaries) ร่วมกับข้อมูลภัยพิบัติแผ่นดินไหวแบบเรียลไทม์จาก USGS

สถาปัตยกรรมและเทคโนโลยีที่ใช้:
• 3D WebGL Visualization: Three.js & Globe.gl Engine
• Geographic Telemetry: Real-time Mouse Raycasting (Latitude & Longitude Calculation)
• Geospatial Data: Natural Earth Geographic Points, PB2002 Tectonic Plates Dataset
• Live Open Data API: USGS Earthquake Real-time GeoJSON API
• Atmospheric Data: Open-Meteo REST API
