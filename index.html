Global Earth Hazard & Climate Monitoring System

แนวคิดและวัตถุประสงค์: พัฒนาระบบแสดงผลธรณีฟิสิกส์บนลูกโลกสามมิติ (3D Virtual Globe Engine) ระดับเทียบเท่า Google Earth โดยเชื่อมต่อข้อมูลเปิด (Open Data) แบบสดจาก USGS และสภาพอากาศแบบเรียลไทม์ ผู้ใช้สามารถหมุน ซูม และบินสำรวจพิบัติภัยได้รอบโลก 360 องศา

เทคโนโลยีและแหล่งข้อมูลหลัก:
• Virtual Globe Engine: CesiumJS (WebGL 3D Earth Graphics Library)
• Satellite Imagery: Esri World Imagery 4K Ultra-sharp Tiles (ฟรี 100%)
• Seismic Telemetry: USGS Earthquake Real-time GeoJSON API
• Global Weather: Open-Meteo REST API
• UI / Design: Glassmorphism HUD, Responsive Tailwind CSS

โครงงานนี้แสดงถึงทักษะด้าน WebGL, Computer Graphics, Geoinformatics (GIS), และการจัดการ Real-time API Integration
