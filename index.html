Global 3D Earth Hazard & Geographic Telemetry System

แนวคิดและที่มา: เว็บแอปพลิเคชันนี้ถูกพัฒนาขึ้นเพื่อใช้เป็นเครื่องมือจำลองลูกโลกเสมือนจริง 3 มิติ (Virtual Globe) ผสานการแสดงผลข้อมูลทางภูมิศาสตร์ พิกัดละติจูด/ลองจิจูด แนวรอยต่อเปลือกโลก และเชื่อมโยงข้อมูลเหตุการณ์แผ่นดินไหวแบบเรียลไทม์จาก USGS และสภาพอากาศจาก Open-Meteo REST API

เทคโนโลยีและแหล่งข้อมูลหลัก (Tech Stack):
• กราฟิก 3 มิติ: Three.js & Globe.gl WebGL Rendering
• ข้อมูลแผ่นดินไหวสด: USGS Earthquake Real-time Feed (ฟรี 100%)
• ข้อมูลสภาพอากาศ: Open-Meteo REST API
• แนวแผ่นเปลือกโลก: PB2002 Global Plate Boundaries
