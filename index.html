Global Hazard & Climate Geophysics Command

แนวคิดและที่มา: เว็บแอปพลิเคชันสำหรับติดตามและวิเคราะห์ความเสี่ยงจากภัยพิบัติทางธรรมชาติ (แผ่นดินไหว) และสภาพบรรยากาศรอบโลก แสดงผลร่วมกับแนวแผ่นเปลือกโลกจริง (Tectonic Plates) เพื่อเป็นสื่อการเรียนรู้เชิงภูมิสารสนเทศ (GIS)

เทคโนโลยีและแหล่งข้อมูล (Tech Stack):
• GIS Engine: Leaflet.js Interactive Mapping Library
• Base Maps: Esri World Imagery (Satellite 4K) & Dark Gray Canvas
• Live Seismic Data: USGS Earthquake Real-time GeoJSON API (ฟรี 100%)
• Weather Data: Open-Meteo REST API (Global Atmosphere)
• Tectonic Boundaries: PB2002 Global Plate Boundary Dataset
