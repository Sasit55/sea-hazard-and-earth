Global 3D Earth Hazard & Geophysical Monitor

Real-Time Geoinformatics & Seismic Analysis Web App

Project Overview: An interactive 3D virtual globe engineered with WebGL to simulate planetary geophysics, tectonic plate dynamics, and real-time natural hazards. Directly integrated with open scientific APIs to provide live telemetry without requiring backend server infrastructure.

Core Technologies & Datasets:
• 3D Engine: Three.js & Globe.gl WebGL Rendering
• Live Seismic Feed: USGS Real-time GeoJSON API (100% Free)
• Global Atmospheric Feed: Open-Meteo REST API
• Tectonic Plate Faults: PB2002 Global Plate Boundary Dataset
• UI / Styling: Modern Cyber Glassmorphism HUD (Tailwind CSS)

Designed for university admission portfolios in Computer Science, Software Engineering, and Geoinformatics (GIS).
